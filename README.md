# Fantasy God-Sim Hackathon Demo

This repository currently contains project scaffolding only. Simulation,
narrative, miracle, and interactive UI behavior are reserved for phase 2.

## Local setup

```bash
npm install
npm run dev
```

The development server prints its local URL in the terminal.

## Verification

```bash
npm run typecheck
npm run build
npm run preview
```

The project is a static Vite + React + TypeScript application intended for
zero-config deployment to Vercel.
